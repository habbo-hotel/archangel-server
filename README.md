# Archangel-Server
Archangel is a habbo roleplay server forked off of Arcturus. It supports corps, gangs, weapons and client improvements

## Developers
* [Chris](https://github.com/chrismpettyjohn) - Roleplay modifications
* [Krews](https://git.krews.org/krews/Morningstar) - Arcturus MS4 Base

## Requirements
Archangel-Server is designed to be paired directly with [Archangel-Client](https://github.com/chrismpettyjohn/Archangel-Client)
